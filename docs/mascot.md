# Mascot mod (text only)

Claude Code mods cannot replace the Clawd mascot or the welcome art. A mod can only draw in these surfaces:

- AbovePrompt band
- Pane
- Spinner
- status line

So this pack's mascot is text only: a short line such as a crew name and a one-word mood, shown in the AbovePrompt band or status line, or spinner verbs in crew voice. No flag artwork, no logos, no character images.

scforge core ships no artwork. You install the mod yourself; the preset only sets `mascot: "strawhat"` as a name the mod can read.
